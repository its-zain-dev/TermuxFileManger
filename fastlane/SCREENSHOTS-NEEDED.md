# Real screenshots for F-Droid

The app screens changed materially between earlier versions and v0.5.0. Previously uploaded screenshots were from old versions, so they were not included as current-version store screenshots.

Capture fresh screenshots after installing the current release and connecting Termux. Recommended: Files home/list, code editor, terminal command output, tools hub, and optional AI assistant. Remove private file paths, API keys, account names and personal data before publishing.

Put them under:
`fastlane/metadata/android/en-US/images/phoneScreenshots/1.png`
`fastlane/metadata/android/en-US/images/phoneScreenshots/2.png`

For tablets use `sevenInchScreenshots` or `tenInchScreenshots`.

The included original featureGraphic.png counts as a graphic for F-Droid's store criteria but is a promotional illustration, not a genuine UI screenshot.
