<b>Termux File Manager (TFM)</b> is a free, open-source Android developer workspace for Termux. Browse files across tabs, edit syntax-highlighted code, run ANSI-colored commands, inspect archives and collaborate with local or cloud AI assistants — all without root.

<b>File manager</b>
• Multi-tab folder browsing for Termux home, $PREFIX and shared storage.
• Filename search and full-text content search (grep) with regex and jump-to-line.
• Category filters, extension sorting, Git branch indicator and live storage meter.
• Persistent Copy/Cut/Paste clipboard, multi-select batch operations and conflict resolution.
• Built-in image previewer, archive inspector/creator/extractor (ZIP & tar.gz with Zip-Slip protection), MD5/SHA-1/SHA-256 checksums, directory disk-usage analyzer, symlinks and visual rwx permission matrix.

<b>Code editor &amp; terminal</b>
• Syntax-highlighted UTF-8 code editor with smart undo/redo, find &amp; replace, coding symbol bar, auto-indent, go-to-line, JSON formatter, Markdown preview, unsaved diff viewer and paginated read-only viewer for large files.
• Multi-session terminal with ANSI color rendering, custom command snippets, searchable command history, interactive Termux launch and one-tap AI debugging.
• Searchable Tools Hub covering Termux packages, Git toolkit, language package managers, local HTTP server, network diagnostics and HTTPS downloads with SHA-256 verification.

<b>Optional AI assistant &amp; local agents</b>
• Works 100% locally offline for files, editor and terminal; AI is strictly optional.
• Supports local self-hosted servers (Ollama / llama.cpp on 127.0.0.1) and optional Termux OpenCode integration, as well as user-configured cloud API providers and ChatGPT sign-in.
• Sixteen guarded assistant tools (including grep_files, surgical edit_file diffs and git_log) with review-before-run approval by default.
• API keys and local service passwords are encrypted using Android Keystore AES-GCM.

<b>Setup &amp; Privacy</b>
Install Termux separately (available on F-Droid or termux.dev), open it once, then follow "Connect to Termux" in TFM. Supports English and Arabic (RTL), five themes plus Material You dynamic colors, and phone/tablet layouts. Contains zero ads, trackers or proprietary SDKs.
