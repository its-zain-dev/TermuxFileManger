<b>مدير ملفات تيرموكس (Termux File Manager)</b> بيئة عمل وتطوير مفتوحة المصدر لأندرويد متكاملة مع Termux، تجمع إدارة الملفات ومحرر الأكواد والطرفية وأدوات التطوير ومساعد الذكاء الاصطناعي الاختياري دون الحاجة لصلاحيات الروت.

<b>إدارة الملفات</b>
• تصفح متعدد التبويبات لمجلد Termux الرئيسي و$PREFIX والتخزين المشترك.
• بحث عن أسماء الملفات وبحث داخل محتوى الملفات (grep) مع التعبيرات النمطية والانتقال المباشر للسطر.
• فلاتر حسب نوع الملف، مؤشر فرع Git الحالي، ومقياس المساحة المتاحة.
• حافظة نسخ ونقل مستمرة، عمليات جماعية مع معالجة التعارضات وسجل العمليات.
• عارض صور مدمج، استعراض وإنشاء وفك أرشيفات ZIP وtar.gz بحماية ضد اختراق المسار، حساب بصمات MD5/SHA-1/SHA-256، محلل مساحة المجلدات، روابط رمزية، ومصفوفة صلاحيات rwx بصرية.

<b>محرر الأكواد والطرفية</b>
• محرر UTF-8 مع تلوين الشيفرة، بحث واستبدال، شريط رموز البرمجة السريع، انتقال للسطر، تنسيق JSON، معاينة Markdown، عرض التغييرات، وعارض صفحات للملفات الكبيرة.
• طرفية متعددة الجلسات تدعم ألوان ANSI، مقتطفات الأوامر المخصصة، سجل الأوامر القابل للبحث، وإرسال الأخطاء للمساعد بضغطة واحدة.
• مركز أدوات شامل لحزم Termux وGit ومديري حزم اللغات وخادم HTTP محلي وتشخيص النظام والتنزيل الآمن عبر HTTPS مع التحقق من SHA-256.

<b>مساعد ذكاء اصطناعي اختياري</b>
• تعمل ميزات الملفات والمحرر والطرفية محليًا بالكامل دون حساب أو إنترنت.
• يدعم الخوادم المحلية (Ollama / llama.cpp على 127.0.0.1) وتكامل OpenCode المحلي الاختياري، بالإضافة إلى مزوّدي API السحابيين وخطة ChatGPT.
• ١٦ أداة محمية للمساعد مع مراجعة الفروقات والأوامر قبل التنفيذ افتراضيًا، وتشفير المفاتيح وكلمات المرور عبر Android Keystore AES-GCM.

<b>الإعداد والخصوصية</b>
ثبّت Termux من F-Droid أو termux.dev، ثم اتبع خطوات "الربط مع Termux". يدعم العربية والإنجليزية، ٥ سمات وميزة الألوان الديناميكية، دون أي تتبع أو إعلانات أو مكتبات مغلقة.
